# Contributing to the Tantry Tulu Font Foundry

Thank you for helping. These fonts, the AccTantra typing standard and the Unicode tools are open source, and good bug reports are one of the most useful things you can give them.

## Reporting a problem

Open an issue in the repository of the font or tool that has the problem, and choose a template.

For a font problem, please include:
- the font and its version (the release tag, for example `v1.4`)
- the keys you typed, and what you expected to see
- a screenshot of what you actually got
- the application and operating system you used

The exact keystrokes matter most, because the AccTantra fonts turn keys into Tulu glyphs.

## Suggesting a change

- **Typing standard (AccTantra):** open an issue in [AccTantra](https://github.com/TantryTuluFonts/AccTantra) before changing key assignments. Every font depends on them, so changes need discussion.
- **A new font that follows the standard:** open an issue to say what you are building. We are happy to list compatible fonts.
- **Documentation fixes:** these can go straight to a pull request.
